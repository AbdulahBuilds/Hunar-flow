🎨 HUNAR Color Usage
Color	Hex	Where to use
🔵 Navy	#123B5D	Brand, navbar, headings, important text
🟢 Teal	#0F8B8D	Main buttons, active states, verified badges
🟠 Orange	#F59E0B	Ratings, highlights, offers, attention
⚪ Background	#F8FAFC	Main website background
⚪ White	#FFFFFF	Cards, navbar, modals, forms
⚫ Dark	#172033	Body text
🌫️ Gray	#64748B	Secondary text, placeholders
🟢 Success	#16A34A	Completed, approved, online
🔴 Error	#DC2626	Cancelled, rejected, errors
1. Navbar
Background: White
HUNAR logo: Navy
Navigation text: Dark/Navy
Active navigation: Teal
Login: Navy outline
Post a Job: Teal

Don't make the entire navbar navy. A white navbar will make HUNAR feel cleaner and more modern.

2. Hero Section
Background: #F8FAFC
Main heading: #123B5D
Description: #64748B
Primary button: #0F8B8D
Secondary button: White + Navy border
Small highlights: Orange

Example:

Find the Right Professional for Your Job
Trusted workers for plumbing, electrical, AC repair and more.

[ Post a Job ] ← Teal
[ Find Professionals ] ← White/Navy

3. Category Cards

For categories like:

Electrician
Plumber
Carpenter
AC Technician
Painter
Mechanic

Use:

Card: White
Icon background: Light Teal
Icon: Teal
Category name: Navy
Description: Gray

Don't give every category a different color. It will make the platform look messy.

4. Professional Cards
Card: White
Professional name: Navy
Profession: Gray
Rating stars: Orange
Verified badge: Teal
Location icon: Gray
Price: Navy
Book/Contact button: Teal

Example:

Ali Khan
Electrician

⭐ 4.8
✓ Verified

📍 Peshawar

Rs. 1,500

[ Book Now ]

5. "Post a Job" Button

This is one of HUNAR's most important actions.

Use:

🟢 Teal #0F8B8D

Don't use orange for the main button.

Orange should attract attention, while teal should represent action/trust.

6. Job Posting Page
Background: #F8FAFC
Form cards: White
Headings: Navy
Labels: Dark
Placeholder: Gray
Input border: Light Gray
Focused input: Teal
Upload area: Light Teal
Post Job button: Teal

When an input is selected:

Border → Teal
Focus ring → Light Teal
7. Worker Offers

This is where orange becomes useful.

Example:

Offer Received

Ahmed Electrician
⭐ 4.9 · ✓ Verified

Visit & Diagnosis: Rs. 300
Estimated Work: Rs. 700
Total Estimate: Rs. 1,000

[ Accept Offer ] ← Teal
[ View Profile ] ← Navy/outline

Use orange for the price/offer highlight, not the whole card.

8. Verified Badge

Use:

🟢 Teal
✓ Verified

Light teal background + teal text.

For example:

#E6F7F7 background
#0F8B8D text

This makes verification visually associated with trust.

9. Booking Status

Use semantic colors:

Status	Color
Pending	Orange
Accepted	Teal
In Progress	Navy
Completed	Green
Cancelled	Red

Example:

🟠 Pending

🟢 Completed

🔴 Cancelled

10. Reviews & Ratings

Use Orange for stars:

⭐⭐⭐⭐⭐

Stars: #F59E0B
Rating number: Navy
Review text: Gray

Don't use teal for stars because orange/gold is immediately understood as a rating.

11. Dashboard
Customer Dashboard
Background: #F8FAFC

Dashboard heading: Navy

Statistics:
Active Jobs → Teal
Pending Offers → Orange
Completed Jobs → Green
Total Spent → Navy

Cards → White

Example:

┌─────────────────┐
│ Active Jobs     │
│                 │
│      03         │
│                 │
└─────────────────┘

Teal icon/accent.

12. Worker Dashboard

Same system:

Available Jobs → Teal
Pending Requests → Orange
Completed Jobs → Green
Earnings → Navy

This keeps the customer and worker sides visually connected.

13. Chat
Your messages: Teal
Worker messages: White
Chat background: #F8FAFC
Text: Dark
Send button: Teal

Avoid using navy message bubbles everywhere—they can become visually heavy.

14. Payment

Payment is a trust-sensitive screen, so keep it simple.

Total amount: Navy
Payment method: White
Selected method: Teal border
Pay button: Teal
Successful payment: Green

Don't use orange for the Pay button.

15. Emergency Services

This is one place where you can use orange more strongly.

For example:

🚨 Emergency Service

Use:

Orange accent
Orange icon
Light orange background

But don't make the entire page orange.

🧠 Simple Rule to Remember

Think of HUNAR's colors like this:

🔵 NAVY = TRUST

Use for:

Logo
Headings
Important text
Professional identity
Dashboard numbers
🟢 TEAL = ACTION

Use for:

Buttons
Booking
Post Job
Accept Offer
Verified
Active states
Links
🟠 ORANGE = ATTENTION

Use for:

Ratings
Offers
Pending status
Important highlights
Emergency accents
🟢 GREEN = SUCCESS

Use only when something is successfully completed.

🔴 RED = DANGER

Use only for:

Errors
Cancellation
Rejection
Delete actions
⭐ HUNAR's Visual Identity

If I were designing the whole HUNAR website, I'd make the visual hierarchy:

Navy → "This is HUNAR / Trust"
Teal → "Take action"
Orange → "Pay attention"
Green → "Success"
Red → "Problem"

That gives HUNAR a professional marketplace identity, rather than looking like a generic repair-services website.
